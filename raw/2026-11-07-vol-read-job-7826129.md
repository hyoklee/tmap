## Code read alongside (clio-core `d2f4edf42`)

- `context-assimilation-engine/core/src/factory/hdf5_file_assimilator.cc`: `format: hdf5_vol`
  calls `StageForVol`, which writes "the HDF5 VOL connector's own cache layout instead of one
  tag per dataset" and refuses a `dst` with a tag name.
- `context-transfer-engine/adapter/hdf5_vol/clio_vol.cc`: a cost gate, on by default
  (`CLIO_VOL_ADMIT_COST=0` turns it off). `clio_device_beats_tier()` returns true once a
  device has at least 4 native read samples of at least 64 KiB (`kDevMinSamples`,
  `kDevSampleMinBytes`) and its measured µs/byte is below the tier's, seeded at
  1200 MB/s (`CLIO_VOL_TIER_MBPS`). When it is true, the file's cache is not used.
