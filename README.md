# tmap

An LLM-maintained wiki about testing the PhysioNet
[TARGET-MAP](https://physionet.org/content/target-map/1.0.0/) dataset with
[CLIO](https://github.com/iowarp/clio). See `CLAUDE.md` for how it works.

TARGET-MAP is restricted-access data under a PhysioNet Data Use Agreement.
**Never commit dataset files to this repo.**
